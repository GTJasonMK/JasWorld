# 听音识阶测试音频

这些文件用于定位手机外放到另一台手机麦克风时的音符识别问题。音频由项目内真实钢琴采样拼接而成，不是合成正弦波。

## 文件与期望结果

- `basic-c4-e4-g4.mp3`: 期望识别为 `C4 E4 G4`。
- `repeat-c4-c4-c4.mp3`: 期望识别为 `C4 C4 C4`。
- `scale-c4-to-c5.mp3`: 期望识别为 `C4 D4 E4 F4 G4 A4 B4 C5`。
- `diagnostic-all.mp3`: 合并版，依次包含上面三组，中间有较长停顿。

## 建议测试方式

优先逐个播放前三个短文件。播放手机音量设置为 50%-70%，另一台手机距离扬声器 20-40cm，环境尽量安静。识别时从音频播放前按住，最后一个音结束后再松开。

测试后请把识别页面显示的音符、保存的“识别音频”，以及你实际播放的是哪个文件一起发回来。
